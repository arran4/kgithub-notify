Fixes #297
Links: #296, #299, #295

**Scope**
This PR implements typed parsing and UI rendering for PR Review and Branch-Lifecycle events.

Exact typed REST events implemented:
- `reviewed`
- `review_dismissed`
- `review_requested`
- `review_request_removed`
- `convert_to_draft`
- `ready_for_review`
- `head_ref_deleted`
- `head_ref_restored`
- `head_ref_force_pushed`
- `base_ref_changed`
- `automatic_base_change_failed`
- `automatic_base_change_succeeded`

**Unavailable/Not Applicable Findings**
- `base_ref_force_pushed`: Found to be a GraphQL-only event. It is not returned by the consumed REST timeline endpoint and is therefore marked as not applicable. We avoid adding a GraphQL dependency purely for this one event.
